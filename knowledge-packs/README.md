# Knowledge packs

Starter reference content for the knowledge library, organised by **specialty
folder**. The folder name becomes the document's domain (e.g. `cardiology/`).
`python -m app.seed demo` (or `seed knowledge`) ingests every pack.

> These are concise **demo reference summaries** written for this project. They
> are not official clinical guidelines. Replace or supplement them with your
> institution's approved guidelines, protocols and drug references.

Supported file types: PDF, DOCX, XLSX, CSV, TXT, MD and JSON (a JSON list of
records becomes one section per record — see `ophthalmology/eye_conditions.json`).
